3. **Q3:** Tap the number **5** on the T-Rex footprint!
   - *Options:* `5` ✅, `3`, `0`
4. **Q4:** Find the number **3** on the Pterodactyl wing!
   - *Options:* `3` ✅, `4`, `1`
5. **Q5:** Tap the number **2** on the jungle rock!
   - *Options:* `2` ✅, `5`, `0`
6. **Q6:** Which dino shield shows number **1**?
   - *Options:* `1` ✅, `4`, `3`
7. **Q7:** Tap the number **0**! (Zero means empty nest!)
   - *Options:* `0` ✅, `2`, `5`
8. **Q8:** Tap the number **5** for victory!

##### 🧩 Group C: `matching` Mechanics (Questions 15 to 20)
15. **Q15:** Match baby dinosaurs to number cards 0–5!
    - *Pair 1:* `3 Baby Dinos 🦕` ↔ `Number 3`
    - *Pair 2:* `4 Dino Eggs 🪺` ↔ `Number 4`
    - *Pair 3:* `5 Footprints 🐾` ↔ `Number 5`
16. **Q16:** Match number 0 to empty nest!
    - *Pair 1:* `0` ↔ `Empty Nest 🪹`
    - *Pair 2:* `1` ↔ `1 Dino Egg 🥚`
    - *Pair 3:* `2` ↔ `2 Dino Eggs 🥚🥚`
17. **Q17:** Match dinosaurs to number flags!
    - *Pair 1:* `4 T-Rexes` ↔ `4`
    - *Pair 2:* `5 Stegosauruses` ↔ `5`
    - *Pair 3:* `3 Raptors` ↔ `3`
18. **Q18:** Match number symbols to color stars!
    - *Pair 1:* `4` ↔ `⭐⭐⭐⭐`
    - *Pair 2:* `5` ↔ `⭐⭐⭐⭐⭐`
    - *Pair 3:* `2` ↔ `⭐⭐`
19. **Q19:** Match dino names!
    - *Pair 1:* `T-Rex` ↔ `Big`
    - *Pair 2:* `Raptor` ↔ `Fast`
    - *Pair 3:* `Pterodactyl` ↔ `Fly`
20. **Q20:** Match numbers 0–5!
    - *Pair 1:* `4` ↔ `Four`
    - *Pair 2:* `5` ↔ `Five`
    - *Pair 3:* `0` ↔ `Zero`
